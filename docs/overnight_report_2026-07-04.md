## 3. 【要判断】本番定数を W1best に変更するか

**推奨: 変更する**（TP 6%→5%、トレーリング ATR×1.5→×2.5。タイムストップ5日は不変）。

- 根拠: W1best は 2022年 IS でブラインドに選定され、**2023〜2025 の純粋 OOS で平均 +0.54%/月（本番値は +0.11%）**。2025年（直近レジーム）の差が最大（+1.61% vs -0.02%）
- リスク量は不変: ハードストップ -2.5% は変えない。トレーリング拡大はハードストップより下には行けない設計
- Caveat: 候補間比較の一部は in-sample 選択を含む（backtest_report §8.12.2 に明記）

**夜間に適用しなかった理由**: cron 実行は 20:30 JST（起床後）で、シグナル枯渇中のため**朝まで待つコストがゼロ**。一方、実運用パラメータの変更は `constants.py` + TP×1.06 前提の単体テスト群 + docs の「利確+6%」表記の一括改修を伴うため、承認を得てから一気に実施するのが安全と判断しました。

**承認いただければ**: constants 変更 → テスト更新 → docs 更新 → WF 再確認 → 当日 20:30 の cron までに反映、まで一括で実施します（見積り: 最良30分〜最悪2時間、テスト波及量次第）。
