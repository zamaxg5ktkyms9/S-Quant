## 投資方針（Phase 1）

| 項目 | 内容 |
|---|---|
| 投資対象 | 東証上場銘柄（株価 ¥100〜¥1,000 の小型株） |
| 売買単位 | **単元株（100株）** ・ SBI証券 |
| 投資資本 | 1ポジション集中・¥100,000 固定 |
| 同時保有 | 最大1銘柄 |
| シグナル生成 | 引け後データ確定後（20:15 JST）に GitHub Actions で毎営業日自動実行 |
| 発注方式 | 引け後シグナル → オペレーター確認 → 翌朝以降に手動発注（成行 + OCO） |
| 発注タイミング | 翌営業日 9:00 以降、始値を確認した上で SBI証券で成行買い → 約定後ただちにOCO（利確指値＋損切り逆指値）をセット |
| 決済方式 | OCO注文によりザラ場で自動執行（一部出口はSlack通知＋手動） |

## 利益目標

| 項目 | 内容 |
|---|---|
| 年間目標 | 平均利益 **¥240,000 / 年**（月次は変動を許容） |
| 月次期待（試算） | Phase 1 月¥1,500〜¥2,500 → Phase 3 月¥15,000〜¥25,000 で目標到達 |
| 月次期待（バックテスト実測） | **Phase 1 月+¥399（+0.40%）** ・ Phase 3換算で月+¥3,990 → 年+¥47,880（目標の約20%） |

### 目標未達ギャップへの方針

Grid Search 2024-2025（180通り）で最適化したベストパラメータでも月+0.40%が天井。**現戦略（押し目モメンタム）と現ユニバース（282銘柄）の組合せでは構造的に目標未達**。

ギャップ解消の選択肢:
1. **シグナル条件の本質見直し**（押し目買い → ブレイクアウト追従型への転換等）
2. **ユニバース拡張**（東証小型株全体から動的抽出）
3. **目標水準の見直し**（年¥240,000 → 年¥50,000相当に下方修正）
4. **Phase 3予算の上振れ検討**（¥1,000,000 → ¥3,000,000 で目標到達）

判断は実運用2ヶ月分の実測データ取得後に行う。

## リスク制約

| 項目 | 内容 |
|---|---|
| 1取引の最大損失 | **投資資本の 3.5%**（Phase 1: ¥3,500） |
| 最長保有期間 | 5営業日（タイムストップ） |
| 年間損失上限 | **投資資本の 30%**（Phase 1: ¥30,000）でサーキットブレーカー発動・全停止 |
| ギャップアップ回避 | 当日始値が前日終値 +2% 超ならオペレーターが当日エントリーを見送る |

### 受容するテールリスク

単元株 + 逆指値で **ザラ場暴落は自動損切り** されるため、S株時の最大の構造リスクは解消。残るテールリスクは以下のみ:

1. **寄りギャップダウン**: 翌朝の始値が想定エントリー価格より大幅安の場合、エントリー価格自体が悪化し、その時点で-2.5%を超えていれば即座にストップ発動して大きく損失確定する可能性。
   - **緩和策**: 始値確認後に「想定ストップ価格を始値時点で割り込んでいたらエントリー自体を見送る」運用ルールを追加。
2. **ストップ価格を大きく飛び越えるザラ場暴落**: 逆指値は逆指値到達後「成行」になるため、流動性が薄いと滑る。
   - **緩和策**: 5日平均売買代金 ¥1億以上の流動性フィルタ。

## 運用上の制約

- **データ**: J-Quants Lightプラン（60 req/min）を使用。レートリミット（429）に対してバックオフと再試行を実装。
- **決算回避**: 決算発表の前後3営業日は対象銘柄から除外（ギャップリスク回避）。
- **半自動**: 発注・OCOセット・トレーリング逆指値更新は手動。システムはシグナルと推奨株数・推奨ストップ価格を Slack 通知する。
- **SBI証券の注文機能**:
  - 単元株（100株単位）取引では指値・成行・**逆指値・OCO・IFD・IFDO** が利用可能。
  - 国内株式現物手数料は「ゼロ革命」適用で **0円**（条件: 各種報告書の電子交付設定）。

## 付録: 段階拡大プラン

実運用とバックテストで実測リターンを確認しながら、3段階で予算を拡大する。

| | Phase 1（検証中） | Phase 2（試験運用） | Phase 3（本運用） |
|---|---|---|---|
| 期間目安 | 〜2026年7月 | 2026年8月〜10月 | 2026年11月以降 |
| 投資資本 | **¥100,000** | ¥300,000 | ¥1,000,000 |
| 対象株価帯 | ¥100〜¥1,000 | ¥100〜¥3,000 | ¥100〜¥10,000 |
| 1取引最大損失 | ¥3,500 | ¥10,500 | ¥35,000 |
| サーキットブレーカー | ¥30,000（30%） | ¥45,000（**15%**） | ¥150,000（**15%**） |
| 月間期待利益 | ¥1,500〜¥2,500 | ¥4,500〜¥7,500 | ¥15,000〜¥25,000 |
| Phase移行条件 | バックテスト＋実運用2ヶ月で月次期待リターン > 1% | Phase2で3ヶ月連続プラスまたは月平均 > 1% | — |

**サーキットブレーカーの率変更根拠**: Phase 1 は学習フェーズで多少のドローダウン許容、Phase 2/3 は絶対損失額が大きくなるため心理・実損双方の許容度を下げる。
