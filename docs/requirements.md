## リスク制約

| 項目 | 内容 |
|---|---|
| 1銘柄の最大損失 | **1銘柄予算 × 2.5%** ≒ Phase 1 で約 ¥1,250／銘柄（旧 ¥3,500 から低下、分散による） |
| 同時保有上限 | Phase 1: 2銘柄、Phase 2/3: 3銘柄 |
| 最長保有期間 | 各銘柄 5営業日（タイムストップ） |
| 年間損失上限（ポートフォリオ全体） | **投資資本の 30%**（Phase 1: ¥30,000）でサーキットブレーカー発動・全停止 |
| ギャップアップ回避 | 各銘柄独立判定。始値が前日終値 +2% 超ならその銘柄のエントリーを見送る（他銘柄は継続）|

### 受容するテールリスク

単元株 + 逆指値で **ザラ場暴落は自動損切り** されるため、S株時の最大の構造リスクは解消。残るテールリスクは以下のみ:

1. **寄りギャップダウン**: 翌朝の始値が想定エントリー価格より大幅安の場合、エントリー価格自体が悪化し、その時点で-2.5%を超えていれば即座にストップ発動して大きく損失確定する可能性。
   - **緩和策**: 始値確認後に「想定ストップ価格を始値時点で割り込んでいたらエントリー自体を見送る」運用ルールを追加。
2. **ストップ価格を大きく飛び越えるザラ場暴落**: 逆指値は逆指値到達後「成行」になるため、流動性が薄いと滑る。
   - **緩和策**: 5日平均売買代金 ¥1億以上の流動性フィルタ。

## 運用上の制約

- **データ**: J-Quants Lightプラン（60 req/min）を使用。レートリミット（429）に対してバックオフと再試行を実装。
- **決算回避**: 決算発表の前後3営業日は対象銘柄から除外（ギャップリスク回避）。
- **半自動**: 発注・OCOセット・トレーリング逆指値更新は手動。システムはシグナルと推奨株数・推奨ストップ価格を Slack 通知する。
- **SBI証券の注文機能**:
  - 単元株（100株単位）取引では指値・成行・**逆指値・OCO・IFD・IFDO** が利用可能。
  - 国内株式現物手数料は「ゼロ革命」適用で **0円**（条件: 各種報告書の電子交付設定）。

**サーキットブレーカーの率変更根拠**: Phase 1 は学習フェーズで多少のドローダウン許容、Phase 2/3 は絶対損失額が大きくなるため心理・実損双方の許容度を下げる。
