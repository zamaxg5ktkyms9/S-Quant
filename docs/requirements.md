## リスク制約

| 項目 | 内容 |
|---|---|
| 1銘柄の最大損失 | **1銘柄予算 × 2.5%** ≒ 約 **¥7,500**／銘柄（1銘柄予算 ¥300,000 × 2.5%） |
| 同時保有上限 | Phase 1: 2銘柄、Phase 2/3: 3銘柄 |
| 最長保有期間 | 各銘柄 5営業日（タイムストップ） |
| 累積損失上限（ポートフォリオ全体） | **投資資本の 15%**（¥600,000 × 15% = **¥90,000**）でサーキットブレーカー発動・全停止。採用パラメータの実測最悪DD -13.1% は 15% 以内（閾値変更不要と判断済み） |
| ギャップアップ回避 | 各銘柄独立判定。始値が前日終値 +2% 超ならその銘柄のエントリーを見送る（他銘柄は継続）|

### サーキットブレーカーの定義（2026-07-03 明確化）

従来「年間損失上限」と表記していたが、実装は暦年ではなく累積判定のため、以下の通り定義する:

- **判定対象**: **Phase 開始来の累積実現損失**（含み損は対象外。個別銘柄ではなくポートフォリオ合計）
- **発動時**: 全取引を停止し Slack に通知。再開は**手動リセットのみ**とし、リセット前に Walk-Forward 再検証（現行レジームでの robust 確認）を必須とする
- **リセット時期**: フェーズ移行（資本・要件の大改定）時に累積カウンタをリセットし、閾値を再計算する。現行閾値: **¥90,000**（¥600,000 × 15%、2026-07-05 増額時にリセット）

### 受容するテールリスク

単元株 + 逆指値で **ザラ場暴落は自動損切り** されるため、S株時の最大の構造リスクは解消。残るテールリスクは以下のみ:

1. **寄りギャップダウン**: 翌朝の始値が想定エントリー価格より大幅安の場合、エントリー価格自体が悪化し、その時点で-2.5%を超えていれば即座にストップ発動して大きく損失確定する可能性。
   - **緩和策**: 始値確認後に「想定ストップ価格を始値時点で割り込んでいたらエントリー自体を見送る」運用ルールを追加。
2. **ストップ価格を大きく飛び越えるザラ場暴落**: 逆指値は逆指値到達後「成行」になるため、流動性が薄いと滑る。
   - **緩和策**: 5日平均売買代金 ¥1億以上の流動性フィルタ。

## 運用上の制約

- **データ**: J-Quants Lightプラン（60 req/min）を使用。レートリミット（429）に対してバックオフと再試行を実装。
- **決算回避**: 決算発表の前後3営業日は対象銘柄から除外（ギャップリスク回避）。
- **半自動**: 発注・損切り逆指値セット・トレーリング逆指値更新は手動。システムはシグナルと推奨株数・推奨ストップ価格を Slack 通知する（TP 廃止に伴い OCO は不要になり、逆指値1本の管理に簡素化）。
- **SBI証券の注文機能**:
  - 単元株（100株単位）取引では指値・成行・**逆指値・OCO・IFD・IFDO** が利用可能。
  - 国内株式現物手数料は「ゼロ革命」適用で **0円**（条件: 各種報告書の電子交付設定）。

## 運用判定基準（移行・撤退・保留）— 2026-07-05 改定（¥600k・noTP 採用に伴う閾値再調整）

判定は**3値**。取引数が少ないうちは 1 取引あたりの分散に判定閾値が埋もれるため、**最低取引数を判定の前提条件**とする（¥600k 化で取引数は年 90〜100 件見込みのため、30 取引 ≈ 3〜4ヶ月で判定可能になる想定）。

| 判定 | 条件 | アクション |
|---|---|---|
| **良好（次の機能フェーズへ投資）** | 累計 **30 取引以上** かつ 月平均リターン > **+0.7%**（採用値4年平均 +1.40% の半値） | 3銘柄分散化 or ユニバース再構築の検証に着手 |
| **撤退（停止・再検証）** | 次のいずれか: ① サーキットブレーカー発動（累積 -¥90,000） ② **3ヶ月連続で月次マイナス** ③ 累計 30 取引以上で実測月平均が **0% 未満**（採用値の最悪年 2023 = -0.04%/月 相当を下回る） | 新規エントリー停止（保有分は出口ルールで手仕舞い）→ 現行レジームで WF 再検証 → 戦略改修 or 廃止を判断 |
| **保留（延長）** | 上記いずれにも該当しない（取引数不足を含む） | 現状継続し翌月再判定。取引数が積み上がらない場合はユニバース健全性（下記）を確認 |

## 運用継続性（可用性）— 2026-07-03 追加

| 事象 | 対応 |
|---|---|
| J-Quants 障害・データ未確定 | 当日のシグナル生成を**スキップ**（シグナルなし扱い）し、Slack に skip 理由を通知。yfinance フォールバックは接続確認用であり、シグナル判定には使わない（データソース混在によるバックテスト整合性の崩壊を防ぐ） |
| GitHub Actions 実行失敗 | Slack 通知で検知。翌営業日の実行で自然回復（当日分のシグナル機会は逸失として許容） |
| オペレーター不在（発注不能） | 新規エントリーは見送り（機会逸失として許容）。**保有分は損切り逆指値が自動執行するため損失は制御済み**。トレーリングストップ未更新は「ストップ幅が広いまま」という許容劣化。タイムストップ売却ができない場合は**翌営業日に成行で実施**（1日超過は許容） |
| earnings_calendar.csv の鮮度 | **四半期ごと**（ユニバース再スクリーニングと同時）に更新。加えて決算シーズン（2・5・8・11月）の前月末に鮮度確認。カレンダーが古いと決算ブラックアウトが機能しないため、更新漏れはリスク制約違反として扱う |

## ユニバース健全性の監視 — 2026-07-05 更新

**経緯**: 2026-06-30 診断で、価格上限 ¥1,000（旧 ¥200k 予算制約）により候補が 1 銘柄/日 まで痩せ細っていることが判明。**2026-07-05 の ¥600,000 増額（上限 ¥3,000）でこの問題は解消**（候補 ≈ 20 銘柄前後、backtest 取引数 年 90〜100 件に回復）。監視は再発検知のため継続する。

**監視要件**:

- 日次のスクリーニング通過数（eligible universe）を記録する（Slack / Sheets）
- **通過数の 20 営業日平均が 3 銘柄未満**になったら構造レビューをトリガーし、以下の選択肢からオーナーが判断する（**予算の再増額は選択肢に含めない** — ¥600k が最終）:
  1. **ユニバース再構築**: 東証全体から ¥100〜3,000 帯で再スクリーニング（四半期メンテの本則）
  2. **単元未満株（S株）の再導入**: 100株単位制約を外す（発注フロー・出口執行の構造変更を伴う）
  3. **低頻度を許容**: 現行のまま運用（機会損失を受容）
  4. **スクリーニング緩和 + WF 再検証**: 流動性・PBR 閾値の緩和はシグナル品質の前提を崩すため、`walk_forward.py` での再検証を必須とする

## 付録: フェーズプラン（2026-07-05 改定 — 資本拡大型から機能拡張型へ）

旧「段階拡大プラン」（Phase 1: ¥200k → Phase 2: ¥300k → Phase 3: ¥1M）は**廃止**する。
予算の逐次増額が繰り返される構造への反省（オーナー指摘）と、**¥600k で限界効率が頂点・¥800k 以上は
統計的根拠なし**という実測（backtest_report §8.14 の松竹梅比較）に基づき、**資本は ¥600,000 で固定**し、
以後のフェーズは資本ではなく**機能**で定義する。

| | 現行（2026-07-05〜） | 機能フェーズ F1（候補） | 機能フェーズ F2（候補） |
|---|---|---|---|
| 内容 | ¥600k・2銘柄・noTP/ATR3.0/TS5 で実運用 | **ユニバース再構築**（東証全体から ¥100〜3,000 帯で再スクリーニング）。**ポイントインタイム要件**: バックテストは各時点で実際に上場していた銘柄で行い（上場廃止銘柄を含む）、可能な範囲でファンダも時点データ化する — 生存者バイアス（§バックテストの既知バイアス）の部分緩和（2026-07-10 外部査読対応で追加） | **3銘柄分散化**（¥200k/枠・上限 ¥2,000）の WF 検証と移行判断 |
| 投資資本 | **¥600,000（固定）** | 変更なし | 変更なし |
| 1銘柄最大損失（-2.5%） | 約 ¥7,500 | 変更なし | 約 ¥5,000（枠 ¥200k 化で低下） |
| サーキットブレーカー | **¥90,000（15%）** | 変更なし | 変更なし |
| 着手条件 | — | [運用判定基準](#運用判定基準移行撤退保留--2026-07-05-改定600knotp-採用に伴う閾値再調整)の「良好」判定、またはユニバース健全性トリガー | F1 完了後、WF で Robust 確認できた場合のみ |

**¥600,000 の根拠（松竹梅実測、全ティア rolling 3窓 WF）**: ¥200k=OOS +0.28%/月（2/3窓）、¥400k=+0.39%（2/3窓）、**¥600k=+0.64%（3/3窓・2023年型レジームでも勝利）**、¥800k=+0.68%（+0.04pt に対し最悪DD -21.5% と悪化）。追加¥200k あたりの限界効果は ¥400k→¥600k が最大で、¥600k→¥800k で急減。

**2銘柄の根拠**: ¥600k ÷ 2 = ¥300k/枠 → 価格上限 ¥3,000 でユニバースを最大化。3銘柄化（¥200k/枠・上限 ¥2,000）は分散でリスクを下げる代わりにユニバースを狭めるトレードオフのため、F2 で WF 検証してから判断する。
