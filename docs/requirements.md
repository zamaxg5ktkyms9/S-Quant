# 要件

## 投資方針

| 項目 | 内容 |
|---|---|
| 投資対象 | 東証上場銘柄（株価 ¥100〜¥3,000 の小型〜中型株） |
| 売買単位 | S株（SBI証券）— 1株から売買可能 |
| 投資資本 | 1ポジション集中・¥100,000 固定 |
| 同時保有 | 最大1銘柄 |
| 発注方式 | 引け後シグナル → オペレーター確認 → 翌営業日に手動発注（**後場成行**） |
| シグナル生成 | 引け後データ確定後（20:15 JST）に GitHub Actions で毎営業日自動実行 |
| 発注タイミング | 翌営業日 9:00〜10:30 の間に発注（S株「後場成行」、約定は 12:30 前場引け後の後場寄り）。**始値（9:00）を確認してから発注可否を判断する**。 |
| 決済タイミング | 同様に翌営業日 9:00〜10:30 に後場成行で発注（約定 12:30） |

## リスク制約

| 項目 | 内容 |
|---|---|
| 1取引の想定最大損失 | ¥3,500（投資額の約3.5%）— **ただし通常時の上限**。下記テールリスク前提を参照 |
| 最長保有期間 | 5営業日（タイムストップ） |
| 年間損失上限 | 累積実現損失 ¥30,000 でサーキットブレーカー発動・全停止 |
| ギャップアップ回避 | **当日始値（9:00）が前日終値 +2% 超** ならオペレーターが当日エントリーを見送る |
| ギャップダウン保有時 | 保有中銘柄の当日始値が前日終値 -3% 超下落の場合、オペレーターが**当日朝の手動成行売り**で即時撤退（システムが Slack で通知） |

### 受容するテールリスク（構造的限界）

S株は逆指値注文が使えないため、以下のリスクは**システムでは制御不能**であり、オペレーターによる目視監視に依存する：

1. **ザラ場暴落**: 寄付き以降に悪材料で日中-10%以上下落しても、システムが検知するのは引け後。翌営業日の後場成行で売却するため、想定¥3,500を大きく超える損失となり得る。
2. **寄りギャップダウン**: 翌朝の始値が前日終値より大きく下振れた場合、エントリー価格が想定より悪化する（事前のギャップダウンキャンセルで一部緩和）。
3. **緩和策**: ① 流動性・時価総額の事前スクリーニングで急騰急落耐性のある銘柄に絞る、② 決算ブラックアウト ±3営業日、③ オペレーターは保有中はザラ場の急変を任意のタイミングでチェックし、異常時は手動成行売却で離脱できる。

## 運用上の制約

- **データ**: J-Quants Lightプラン（60 req/min）を使用。レートリミット（429）に対してバックオフと再試行を実装。
- **決算回避**: 決算発表の前後3営業日は対象銘柄から除外（ギャップリスク回避）。
- **半自動**: 発注・決済は手動。システムはシグナルと推奨株数を Slack 通知するのみ。
- **S株の約定タイミング**（SBI証券仕様）:
  - 前営業日 16:00 〜 当日 7:00 までの発注 → **前場始値（9:00）で約定**
  - 当日 7:00 〜 10:30 までの発注 → **後場始値（12:30）で約定**
  - 当日 10:30 〜 13:30 までの発注 → **翌営業日の前場始値で約定**
  - 本システムは「**始値を確認してから発注可否を判断する**」運用のため、後者（後場成行）を採用。
