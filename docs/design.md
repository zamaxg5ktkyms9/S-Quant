## 戦略コンセプト

本システムは「**上昇トレンド中の押し目を拾う短期モメンタム戦略**」を自動化したものです。

大きな流れ（75日MA）に乗りながら、短期的な売られすぎ（RSI低下）かつボラティリティが収縮しているタイミングを狙う。エントリー後は最大5営業日で必ず手仕舞いし、含み損の長期化を防ぐ。

**Phase 1（¥100,000）の対象は東証小型株（株価¥100〜¥1,000）に絞る**。単元株（100株単位）取引を使用し、SBI証券の逆指値・OCO注文でザラ場の損切り・利確を機械化する。

## スクリーニング条件

流動性の低い銘柄・財務的に脆弱な銘柄・割高銘柄を事前に除外し、シグナルの誤検知を減らす。

| 項目 | 条件（Phase 1） | 根拠 |
|---|---|---|
| 株価 | **¥100 〜 ¥1,000** | 単元株100株 × ¥1,000 = ¥100,000 の予算制約。¥100未満はスプレッド過大 |
| 時価総額 | ¥30億以上 | 極小型株はニュース1本で急騰急落しやすく、テクニカル分析が機能しにくい |
| 流動性 | 5日平均売買代金 ¥1億以上 | 売買代金が薄い銘柄は逆指値発動時のスリッページが大きくなる |
| PBR | 0.5 〜 2.0 倍 | 0.5倍未満は解散価値割れ（業績悪化懸念）、2.0倍超は割高 |
| 自己資本比率 | 30%以上 | 30%未満は財務レバレッジが高く、外部環境の変化に脆弱 |
| 決算ブラックアウト | ±3営業日は除外 | 決算前後のギャップリスクを回避 |

> **用語**
> - *PBR（株価純資産倍率）*: 株価 ÷ 1株当たり純資産。企業の解散価値に対する割安・割高の目安。
> - *自己資本比率*: 純資産 ÷ 総資産。高いほど借金が少なく財務的に安定。

## シグナル条件

4条件すべてを満たした銘柄のみをエントリー候補とする。

| 条件 | 内容 | 根拠 |
|---|---|---|
| ① トレンド | 終値 > 75日移動平均 | 長期上昇トレンドが続いていることを確認 |
| ② RSI(14) | **35 < RSI < 60** | Grid Search 2024-2025 のベスト。上限を50→60に拡張するとシグナル数3倍・期待値プラス転換 |
| ③ ボラティリティ | 20日間標準偏差 < 過去60日標準偏差の平均 | 価格変動幅が縮小している局面はエネルギー蓄積（ブレイクアウト前兆） |
| ④ 出来高サージ | 当日出来高 > 20日平均出来高 × 1.2 | 実需を伴う反転を確認。「終値>5日MA」は ② と矛盾するため削除 |

> **設計変更の根拠（旧シグナルからの差分）**
> 1. **旧S株版「RSI(5)<45 + 終値>5日MA」は両立せず**: RSI(5)が短期反転で急上昇するため数学的にほぼ成立しない。実ライブ（2026-05-22）スクリーナー通過29件中シグナル0件。
> 2. **改訂版「RSI(14) 35〜50」も狭すぎた**: 初回バックテスト（2024-2025）でシグナル20件・累積-14%・PF 0.30。押し目だけに絞ったため、シグナル発生数が月0.8回と少なく、しかも「落下中のナイフ」を掴むことが多かった。
> 3. **Grid search でRSI上限60が最良**: 押し目ゾーン拡大により月2件発生、累積+9.5%・PF 1.20に改善。Top 14件すべてが rsi_upper=60。
> 4. **ブレイクアウト追従への転換実験 → 不採用（2026-05-23）**: 20日高値ブレイク + 出来高×1.5 + RSI 30-80 でバックテストしたところ、累積-16.9%・PF 0.72・勝率33.3%と悪化。保有1日でストップアウト29件（54%）= 「ダマシブレイク後の即売り叩き」が頻発。**Grid Search ベスト（押し目モメンタム）に戻して実運用フェーズへ進む**判断。

> **用語**
> - *RSI（相対力指数）*: 0〜100で推移する勢い指標。一般に30以下で売られすぎ、70以上で買われすぎ。
> - *移動平均（MA）*: 過去N日間の終値の平均。トレンド方向の平滑化。

候補が複数の場合は **RSI昇順 → 出来高サージ率降順 → PBR昇順** でランキングし、上位1銘柄を選出。

## 発注数量

```
最悪ケース執行価格 = 前日終値 × (1 + 2%)  ← ギャップアップ上限
最大株数 = floor(min(残高, 投資資本) / 最悪ケース執行価格)
発注株数 = floor(最大株数 / 100) × 100      ← 単元株なので100株単位
```

Phase 1（¥100,000）で株価¥800の銘柄をエントリーする例:
- 最悪ケース執行価格 = 800 × 1.02 = 816
- 最大株数 = floor(100,000 / 816) = 122
- 発注株数 = floor(122 / 100) × 100 = **100株**
- 実投下額 ≈ ¥80,000、残¥20,000は遊休

## 発注フロー

### エントリー

| ステップ | 時刻 | 担当 | 内容 |
|---|---|---|---|
| 1 | 当日 20:15 | システム | シグナル検出 → Slack通知（銘柄・推奨株数・想定エントリー価格・**推奨ストップ価格**・**推奨利確価格**） |
| 2 | 翌営業日 9:00 | オペレーター | 始値確認。下記いずれかでエントリー見送り:<br>・始値 > 前日終値 × 1.02（ギャップアップ）<br>・始値 ≤ 推奨ストップ価格（ギャップダウンで即ストップ圏内） |
| 3 | 9:00以降の任意時刻 | オペレーター | SBI証券で**成行買い**発注 → 即時約定 |
| 4 | 約定直後 | オペレーター | SBI証券で**OCO注文**をセット:<br>・利確指値: エントリー価格 × 1.06（+6%）<br>・損切り逆指値: エントリー価格 × 0.975（-2.5%） |
| 5 | 約定情報 | オペレーター | Slack の専用スレッドに約定価格・株数を返信 → システムが Sheets に保存 |

### 保有中の出口管理

| 出口 | 発動 | 実装 |
|---|---|---|
| ハードストップ -2.5% | ザラ場で価格到達 | OCO逆指値で**自動執行** |
| 利確 +6%（×1.06） | ザラ場で価格到達 | OCO指値で**自動執行** |
| トレーリングストップ | 毎営業日 20:15 にシステムが計算 | Slack通知 → オペレーターがSBI証券で**逆指値価格を切り上げ**（OCOを再セット） |
| タイムストップ（5営業日） | 5営業日経過 | 5日目の引け後にシステムが通知 → オペレーターが OCO キャンセル＋翌朝成行売却 |

## 出口ルール詳細

### 優先順位

| 優先度 | ルール | 発動条件 | 実装 |
|---|---|---|---|
| 1 | ハードストップロス | 株価 ≤ エントリー価格 × (1 - 2.5%) | SBI逆指値（OCO） |
| 2 | トレーリングストップ | 株価 ≤ max(ハードストップ, 直近高値 - 2.5×ATR(14)) | システム計算 → 手動でSBI逆指値更新 |
| 3 | 利確 | 株価 ≥ エントリー価格 × 1.06（+6%） | SBI指値（OCO） |
| 4 | タイムストップ | 保有5営業日経過 | システム通知 → 手動成行売却 |

> **優先順位の根拠（バックテストの保守的扱い）**
> 実運用ではOCOに利確指値と逆指値が同時にセットされるため、ザラ場で先に到達した方が約定する。しかしバックテストでは1日の中の到達順序は OHLC からは復元できない。同日に「安値 ≤ ストップ」かつ「高値 ≥ 利確」が両方成立した場合、**保守的にストップ優先**として損失側を計上する。これにより期待値が過大評価されない。
> 実装: `src/squant/domain/position_manager.py` の `evaluate_exit` がこの順序で判定する。

### 利確価格の計算

```
利確価格 = エントリー価格 × (1 + 6%) = エントリー価格 × 1.06
```

**Phase 1（単元株・SBI手数料0円）ではスプレッドコストは実質ゼロ**。S株時代の両端 0.5% 補正（旧式 ≈ ×1.0716）は不要。実装の `compute_take_profit_price` は `spread_rate=0` をデフォルトとし、純粋な ×1.06 を返す。

### リスク・リワード比率（理論値）

| 項目 | 値 |
|---|---|
| 想定最大損失 | -2.5%（OCO逆指値で機械執行、スリッページ小） |
| 想定利確目標 | +6.0% |
| R:R 比率 | **1 : 2.40** |
| 損益分岐勝率 | 約 29% |

### バックテスト実測（2024-01 〜 2025-12、Phase 1 ¥100,000）

| 指標 | 実測値 |
|---|---|
| 取引件数 | 49件（2.05件/月） |
| 勝率 | 44.9%（22勝27敗） |
| 累積損益 | **+¥9,527（+9.5% / 2年）** |
| 月平均損益 | **+¥399（+0.40% / 月）** |
| 平均利益 vs 平均損失 | +¥2,573 vs -¥1,744 |
| プロフィットファクター | **1.20** |
| 最大ドローダウン | -¥16,764（-16.8%） |
| 出口理由 | STOP_LOSS 19・TAKE_PROFIT 7・TRAILING_STOP 13・TIME_STOP 10 |

> **目標未達であることへの注記**
> 月+0.40% は Phase 3（¥1,000,000）換算でも年¥47,880 にしかならず、目標¥240,000の約20%。
> 現戦略（押し目モメンタム + 現ユニバース282銘柄）でのパラメータ最適化はほぼ限界に達している。
> 次の改善余地はパラメータではなく**シグナル条件の本質見直し**（押し目買い → ブレイクアウト追従への転換等）またはユニバース拡張。

### パラメータ確定値（Grid Search 2024-2025 ベスト）

| パラメータ | 確定値 | Grid 探索レンジ | 採用根拠 |
|---|---|---|---|
| ハードストップ | -2.5% | （固定） | 最大損失制約を維持 |
| 利確目標 | **+6.0%** | +2% 〜 +6% | Top 4件中3件が +6%。下げると微益決済増えてPF低下 |
| ATR乗数 | **1.5** | 1.5 〜 2.5 | 狭めの方が利益確保が早い。2.5は広すぎて利益逃す |
| トレーリング基準 | 直近高値 - 1.5×ATR | （固定） | 終値ベースはラチェット不成立 |
| ATR期間 | 14 | （固定） | — |
| RSI(14)上限 | **60** | 45 〜 60 | Top 14件すべてが 60。狭めるとシグナル不足 |
| RSI(14)下限 | 35 | （固定） | 押し目ゾーン下限。これ未満は下落圧力強すぎ |
| タイムストップ | 5営業日 | 3 〜 7 | 3/5/7に大差なし、5日が安定 |
| 出来高サージ倍率 | 1.2 | （固定） | — |

> **用語**
> - *ATR（Average True Range）*: 過去N日間の真の値幅平均。銘柄ごとのボラティリティに応じてストップ幅を自動調整。
> - *OCO（One-Cancels-the-Other）*: 利確指値と損切り逆指値を同時に出し、片方が約定したら他方を自動キャンセルする注文方式。
> - *トレーリングストップ*: 上昇につれてストップを切り上げ、利益を守りながらトレンドを追いかける仕組み。下落時は下がらない（ラチェット）。

## リスク管理

### サーキットブレーカー

累積実現損失が **投資資本の30%（Phase 1: ¥30,000）** を超えると全取引を停止し、Slack に通知する。手動リセットが必要。

### ステートマシン

```
IDLE → PENDING_SIGNAL → HOLDING → SETTLING → IDLE
```

各状態は Google Sheets で永続化される。二重エントリーはべき等性ガードで防止。

### Phase 1 で特に監視する事項

バックテスト（2024-2025）実測値との乖離を計測:

- 月次シグナル発生回数（バックテスト実測 月2件 / 目標 月3〜6回）
- 月次リターン（バックテスト実測 +0.40% / 目標 +1.5%以上）
- 勝率（バックテスト実測 44.9%）
- 約定スリッページ（特に逆指値発動時）
- 寄りギャップダウンの頻度・規模
- トレーリングストップ更新の手動運用負荷

実測がバックテストを下回り続ける場合は、戦略本体（シグナル条件 or ユニバース）の見直しを検討。

## 付録: Phase 2 / Phase 3 への拡張

予算拡大に伴う設計変更点。**コードレベルでは投資資本を環境変数化することで吸収可能**にしておく。

| パラメータ | Phase 1 | Phase 2 | Phase 3 |
|---|---|---|---|
| 投資資本 | ¥100,000 | ¥300,000 | ¥1,000,000 |
| 対象株価帯 | ¥100〜¥1,000 | ¥100〜¥3,000 | ¥100〜¥10,000 |
| 1取引最大損失 | ¥3,500（資本×3.5%） | ¥10,500（資本×3.5%） | ¥35,000（資本×3.5%） |
| サーキットブレーカー | ¥30,000（資本×30%） | ¥45,000（資本×15%） | ¥150,000（資本×15%） |
| 必須環境変数 | `CAPITAL=100000` | `CAPITAL=300000` | `CAPITAL=1000000` |

### Phase移行時のチェックリスト

1. 直前Phaseで「月次期待リターン > 1%」の実測がN月分（Phase 1→2: 2ヶ月、Phase 2→3: 3ヶ月）
2. バックテスト再実行で新Phaseの株価帯でも期待値プラス
3. サーキットブレーカー比率を 30% → 15% に厳格化
4. 流動性条件の見直し（Phase 3 では平均売買代金 ¥3億以上に引き上げ検討）
5. SBI証券側の取引履歴・残高と Google Sheets の同期確認
