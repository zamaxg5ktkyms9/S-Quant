# 設計

## 戦略コンセプト

本システムは「**上昇トレンド中の押し目を拾う短期モメンタム戦略**」を自動化したものです。

大きな流れ（75日MA）に乗りながら、短期的な売られすぎ（RSI低下）かつボラティリティが収縮しているタイミングを狙う。エントリー後は最大5営業日で必ず手仕舞いし、含み損の長期化を防ぐ。

---

## スクリーニング条件

流動性の低い銘柄・財務的に脆弱な銘柄・割高銘柄を事前に除外し、シグナルの誤検知を減らす。

| 項目 | 条件 | 根拠 |
|---|---|---|
| 株価 | ¥100 〜 ¥3,000 | S株でも¥100未満は実質スプレッドが大きい。¥3,000超は¥100,000予算で株数が少なくなる |
| 時価総額 | ¥30億以上 | 極小型株はニュース1本で急騰急落しやすく、テクニカル分析が機能しにくい |
| 流動性 | 5日平均売買代金 ¥1億以上 | 売買代金が薄い銘柄はスプレッドが広がりやすく実質コストが増大する |
| PBR | 0.5 〜 2.0 倍 | 0.5倍未満は解散価値割れ（業績悪化懸念）、2.0倍超は既に割高と判断して除外 |
| 自己資本比率 | 30%以上 | 30%未満は財務レバレッジが高く、外部環境の変化に脆弱 |
| 決算ブラックアウト | ±3営業日は除外 | 決算前後のギャップリスクを回避 |

> **用語**
> - *PBR（株価純資産倍率）*: 株価 ÷ 1株当たり純資産。企業の解散価値に対する割安・割高の目安。
> - *自己資本比率*: 純資産 ÷ 総資産。高いほど借金が少なく財務的に安定。

## シグナル条件

4条件すべてを満たした銘柄のみをエントリー候補とする。

| 条件 | 内容 | 根拠 |
|---|---|---|
| ① トレンド | 終値 > 75日移動平均 | 長期上昇トレンドが続いていることを確認。トレンドに逆らわない |
| ② RSI(14) | 35 < RSI < 50 | 中期的な売られすぎ〜中立を捉える。RSI(5)<45 は終値>5日MAとほぼ両立せず実証で 0 件となったため、期間14に切り替え押し目ゾーンを下限35で限定 |
| ③ ボラティリティ | 20日間標準偏差 < 過去60日標準偏差の平均 | 価格変動幅が縮小している局面はエネルギーが蓄積された状態（ブレイクアウト前兆） |
| ④ 出来高サージ | 当日出来高 > 20日平均出来高 × 1.2 | 実需を伴う反転を確認。「終値>5日MA」は ② と矛盾するため削除し、出来高条件を強化 |

> **設計変更の根拠（旧シグナルからの差分）**
> 旧設計の「RSI(5)<45 かつ 終値>5日MA」は数学的にほぼ両立しない（RSI(5)が短期反転で急上昇するため）。実ライブ（2026-05-22）でもスクリーナー通過29件中シグナル0件。
> 改訂版では RSI(14) の中立〜押し目ゾーン（35〜50）でフィルタし、5日MA条件を出来高サージ条件に置き換えた。
> 最終的な閾値（RSI上下限・出来高倍率）はバックテストで調整する。

> **用語**
> - *RSI（相対力指数）*: 0〜100で推移する勢い指標。一般に30以下で売られすぎ、70以上で買われすぎとされる。
> - *移動平均（MA）*: 過去N日間の終値の平均。トレンドの方向を平滑化して確認する。

候補が複数の場合は **RSI昇順 → 出来高サージ率降順 → PBR昇順** でランキングし、上位1銘柄を選出。

## 発注数量・発注方式

```
最悪ケース執行価格 = 前日終値 × (1 + 2%)  ← ギャップアップ上限
株数 = floor(min(残高, ¥100,000) / 最悪ケース執行価格)
```

### 発注フロー（S株「後場成行」）

| ステップ | 時刻（翌営業日） | 内容 |
|---|---|---|
| 1 | 9:00 | オペレーターは始値を確認 |
| 2 | 9:00〜10:30 | 始値が前日終値 × 1.02 **以下**ならSBI証券で「成行」発注、超なら見送り |
| 3 | 12:30 | 後場寄りで約定（市場仕様） |

**ギャップアップキャンセルの実装根拠**: 前場成行（7:00前発注）は 9:00 自動約定のため始値確認後のキャンセル不可。後場成行に統一することで、始値（=ギャップ）を確認してから発注判断が可能となる。

**トレードオフ**:
- シグナル時点（前日 15:00 終値）から約定（翌日 12:30）まで約21.5時間の価格変動を被る。
- 後場寄りは前場寄りよりやや薄いが、対象銘柄は5日平均売買代金¥1億以上に限定しているためスリッページは限定的。
- 朝の急騰銘柄（ギャップアップで上昇継続）の利益は取り逃がす可能性があるが、これはギャップアップキャンセル方針と一貫している。

## 出口ルール

保有中は毎営業日の終値で以下の順に評価し、最初に該当したものが発動する（決済発注は翌営業日の後場成行）。

### 優先順位

| 優先度 | ルール | 発動条件 | 根拠 |
|---|---|---|---|
| 1 | **緊急離脱（手動）** | オペレーターがザラ場で異常急落（前日終値比 -5% 超等）を目視確認 | システム自動検知不可のため。テールリスク緩和策 |
| 2 | タイムストップ | 保有5営業日経過 | 含み損の長期化・機会損失を防ぐ絶対条件 |
| 3 | ハードストップロス | 終値 ≤ エントリー価格 × (1 - 2.5%) | 想定外の急落に対する損失上限 |
| 4 | トレーリングストップ | 終値 ≤ max(ハードストップ, 直近高値 - 2.5×ATR(14)) | 上昇に追随してストップを切り上げ、利益を守る |
| 5 | 利確 | 終値 ≥ 利確価格（純利益+6%） | 目標達成で機械的に確定 |

### パラメータ調整方針（初期値）

| パラメータ | 旧値 | 新初期値 | 根拠 |
|---|---|---|---|
| トレーリングストップ ATR乗数 | 1.5 | **2.5** | 小型〜中型日本株の日中ノイズに対し1.5は狭すぎる。一般的レンジ2.0〜3.0の中央寄り |
| トレーリングストップ基準価格 | 「終値 - 1.5×ATR」 | **「直近高値 - 2.5×ATR」** | 「終値基準」ではトレーリング機能が働かない（ラチェット不成立）。保有中の最高値を基準にする |
| 利確目標（純利益） | +4% | **+6%** | R:R改善（後述） |
| ATR期間 | 14 | 14（変更なし） | — |

### 利確価格の計算

```
利確価格 = エントリー価格 × (1 + 0.5%) × (1 + 6%) / (1 - 0.5%)
         ≈ エントリー価格 × 1.0716
```

S株の売買スプレッド（片道0.5%）を加味した**純利益ベースの +6%** で算出。

### リスク・リワード比率

| 項目 | 値 |
|---|---|
| 想定最大損失（通常時） | -3.5%（-2.5% ストップ ＋ 両端スプレッド 0.5%×2） |
| 想定利確目標（純利益） | +6.0% |
| R:R 比率 | **1 : 1.71**（旧 1:1.14 から改善） |
| 損益分岐勝率 | 約 37%（旧 約 47%） |

旧設計は5日タイムストップによる「同値〜微損撤退」が多発した場合、R:R 1.14では損益分岐勝率55%超が要求され期待値マイナスのリスクが高かった。利確を+6%、トレーリング2.5×ATRに広げることで、勝ち判定の余地と利益伸ばし幅を確保する。

### 実質最大損失（通常時）

```
最大損失 ≈ 投資額 × 3.5%（スプレッド込み）
         = ¥100,000 × 3.5% = ¥3,500
```

> ⚠ ザラ場暴落・寄りギャップダウン時は上記を上回る損失となり得る（[requirements.md「受容するテールリスク」](requirements.md) 参照）。

### バックテスト後の再調整項目

以下はバックテスト結果に基づき再調整する（現在は初期値）:
- ATR乗数（2.0〜3.0 で grid search）
- 利確目標（+4%〜+8%）
- ハードストップ（-2.0%〜-3.0%）
- RSI(14) のしきい値（35〜50 のバンド幅）
- 出来高サージ倍率（1.0〜1.5）

> **用語**
> - *ATR（Average True Range）*: 過去N日間の真の値幅（高値-安値・前日終値とのギャップを考慮）の平均。銘柄ごとのボラティリティに応じてストップ幅を自動調整する。
> - *トレーリングストップ*: 上昇につれてストップを切り上げ、利益を守りながらトレンドを追いかける仕組み。下落時は下がらない（ラチェット）。

## リスク管理

### サーキットブレーカー

累積実現損失が ¥30,000 を超えると全取引を停止し、Slack に通知する。手動リセットが必要。

### ステートマシン

```
IDLE → PENDING_SIGNAL → HOLDING → SETTLING → IDLE
```

各状態は Google Sheets で永続化される。二重エントリーはべき等性ガードで防止。
